# Setup

---
## Docker
- Docker Engine **version:** ``> 4.43.1``
- Docker Compose **version:** ``> v2.30.3-desktop``

---
## Быстрый запуск

### setup.bat (рекомендуется)
Автоматически запускает всю систему:
```cmd
setup.bat
```

### setup.py (альтернатива)
Простой Python скрипт для запуска:
```cmd
python setup.py
```
- Python **version:** `> 2.4 ;)`(any)

### Ручной запуск
```cmd
docker-compose up -d --build
```

---
## После запуска

- **Веб-приложение**: http://localhost:8080
- **API документация**: http://localhost:8080/api/
- **Тест БД**: http://localhost:8080/api/testdb
